IPv6邻居请求

通过发送IPv6邻居请求(Neighbor Solicitation)，让网关学习并转发容器的IPv6流量

邻居请求配置

该功能需要以root权限运行本服务（使用原始套接字发送IPv6邻居请求），且需设置内核参数 net.ipv6.ip_nonlocal_bind 与 net.ipv6.conf.all.proxy_ndp。
启用IPv6邻居请求
开启后将随流量监控轮询，对匹配前缀的容器IPv6发送邻居请求
仅对以此前缀开头的容器IPv6地址发送邻居请求

说明

  • 启用后，本服务每隔一个流量监控采集周期，对每个运行中容器中匹配前缀的IPv6地址发送邻居请求。
  • 请求目标为配置的网关地址，使网关学习到该IPv6对应的邻居转发关系。
  • 发送的源地址为容器自身的IPv6地址。
  • 开启后会为每个匹配前缀的容器IPv6添加内核代理邻居条目（等价 ip -6 neigh add proxy），网关重新解析地址时本机可持续应答。
  • 关闭主开关、修改网卡/前缀时，会自动清理匹配前缀的代理NDP条目；容器删除或重装换址时也会清理旧条目。
  • 关闭主开关后停止发送（不执行内核参数设置）。
